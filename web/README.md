# Той шақыру (жұмыс атауы) – MVP

Онлайн той шақыру + RSVP + қонақтар тізімі. ТЗ: `../founder/TZ.md`.

## Іске қосу (dev)

```bash
cp .env.example .env            # құпиясөз бен SESSION_SECRET-ті өзгертіңіз
npm install
npx prisma db push               # PostgreSQL кестелерін жасайды
npm run db:seed                  # LAUNCH30 промокоды + демо шақыру
npm run dev                      # http://localhost:3000
```

Production: `npm run build && npm start`. Күнде бір рет: `npm run cleanup` (тойдан 90 күн өткен соң қонақ деректерін өшіреді).

## Беттер

| жол | кімге | не |
|---|---|---|
| `/` | бәрі | Басты бет, мысалдар, бағалар, WhatsApp |
| `/{slug}` | қонақ | Шақыру, RSVP, үлкендер режимі, қаз/орыс (`?s=qr` QR арқылы) |
| `/p/{previewToken}` | той иесі | Алдын ала көрініс (су белгісі, RSVP өшік) |
| `/manage/{ownerToken}` | той иесі | Тізім, қолмен қосу, Excel, QR, еске салу |
| `/admin` | әкімші | Тапсырыстар, редактор, төлем, промокодтар |

## Атауды өзгерту

Бренд атауы бір жерде: `src/lib/brand.ts` → `BRAND.name`.

## ТЗ-дан әзірге айырмашылықтар (келесі қадамдар)

- Әкімшіге TOTP (2FA) әлі жоқ, тек құпиясөз + сәтсіз кіруге шек (ТЗ A-1).
- PDF экспорт жоқ, тек XLSX (ТЗ O-5).
- Үлгілер кодта (`src/lib/templates.ts`), дерекқор кестесінде емес.
- OG сурет: шақырудың бірінші фотосы; автоматты 1200×630 сурет жоқ (ТЗ F-8).
- Фото сығылмайды (WebP-ке айналдыру жоқ, ТЗ A-3).
- Файлдар жергілікті дискіде (`UPLOAD_DIR`), S3 емес.
- RSVP rate limit жадта (бір сервер үшін жеткілікті).
- Аналитика (ТЗ §3.6 T-2) қосылмаған.
- Құпиялық саясаты мен оферта – жоба мәтін, заңгер тексеруі керек.
