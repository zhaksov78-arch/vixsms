## 1. Жоба туралы

### 1.1 Мақсат
Той иесіне екі нәрсе беретін веб-сервис жасау керек:
- **шақыру сайты:** әдемі, мобильді, қазақ және орыс тілдерінде;
- **нақты қонақ саны:** RSVP, қонақтар тізімі және тойханаға арналған экспорт.

### 1.2 Пайдаланушылар (рөлдер)

| рөл | кім | не істейді |
|---|---|---|
| **Қонақ** | Шақыру алған адам, 15–80 жас, көбіне телефоннан кіреді | Шақыруды ашады, «келемін / келе алмаймын» деп жауап береді |
| **Той иесі** | Тапсырыс беруші (ата-ана немесе оның баласы) | Алдын ала көріністі көреді, төлейді, қонақтар тізімін бақылайды, қонақ қосады |
| **Әкімші** | Сіз немесе көмекшіңіз | Шақыру жасайды, үлгілерді басқарады, тапсырыстар мен төлемдерді жүргізеді |
| **Серіктес** | Асаба, тойхана, фотограф | Промокодпен клиент әкеледі (MVP-де тек промокод бойынша есеп жүргізіледі) |

### 1.3 MVP-ге не кіреді, не кірмейді

**MVP-ге кіреді (1 желтоқсанға дейін):**
- Шақыру беті: үлгілер, RSVP, үлкендерге арналған режим, дауыстық шақыру, карта, кері санақ таймері, музыка.
- Той иесінің панелі: қонақтар тізімі, қонақты қолмен қосу, экспорт, QR-код, еске салу мәтіні.
- Әкімші панелі: шақыру жасау және өңдеу, «алдын ала көрініс / жарияланған» күйлері.
- Kaspi арқылы төлем: төлем сілтемесі немесе QR. Төлемді әкімші қолмен растайды.
- Басты бет: портфолио (3 мысал), бағалар, WhatsApp батырмасы.
- Промокодтар (серіктестер мен акциялар үшін).

**MVP-ден кейін (v2):**
- Клиент өзі жасайтын конструктор (3 900 ₸).
- Kaspi Pay API арқылы төлемді автоматты растау.
- WhatsApp Business API арқылы автоматты хабарламалар.
- Серіктестерге арналған жеке кабинет.
- Видео-шақыру жасау құралы.

## 2. Пайдаланушы сценарийлері

### 2.1 Тапсырыс (әкімші мен той иесі)
1. Той иесі басты беттен WhatsApp арқылы жазады.
2. Әкімші той иесінің мәліметтерін алып, панельде жаңа шақыру жасайды. Шақыру `draft` күйінде болады.
3. Әкімші «Алдын ала көрініс» батырмасын басады. Жүйе `/p/{preview_token}` сілтемесін жасайды. Алдын ала көріністе:
   - «АЛДЫН АЛА КӨРІНІС» деген су белгісі тұрады;
   - RSVP өшірулі болады;
   - іздеу жүйелері бетті индекстемейді (noindex).
4. Той иесі түзету сұрайды, әкімші өңдейді. Алдын ала көрініс сілтемесі сол күйі қалады.
5. Той иесі Kaspi арқылы төлейді. Әкімші «Төленді» батырмасын басады. Шақыру `published` күйіне өтеді.
6. Жүйе той иесіне мыналарды береді:
   - қонақтарға арналған сілтеме `/{slug}`;
   - той иесінің панеліне кіретін құпия сілтеме `/manage/{owner_token}`;
   - QR-кодтың PNG файлы.

### 2.2 Қонақ
1. Қонақ WhatsApp-та сілтемені ашады. Чатта сілтеменің әдемі алдын ала көрінісі шығады (OG сурет, той иелерінің аты, күні).
2. Ашылған беттің жоғарғы жағында екі батырма тұрады: **«Үлкен әріппен көру»** және тілді ауыстыру (ҚАЗ / РУС).
3. Қонақ шақыруды оқиды: дауыстық шақыруды тыңдайды, картаны ашады, бағдарламаны көреді.
4. RSVP:
   - **«Келемін»** таңдалса: аты-жөнін, қанша адаммен келетінін (1–10) және қаласа телефон нөмірін енгізеді;
   - **«Келе алмаймын»** таңдалса: тек аты-жөнін енгізеді.
5. Жауаптан кейін «Рахмет! Сізді күтеміз» деген хабарлама шығады. Жауапты өзгерту батырмасы да бар.

### 2.3 Той иесінің панелі
- Жалпы санды көреді: «Келеді: 214 адам (87 жауап) · Келмейді: 12».
- Тізімді көреді: аты, адам саны, жауап арнасы (сайт, QR, қолмен қосылған), уақыты.
- **«Қонақ қосу»** батырмасы: телефонмен жауап берген қонақтарды қолмен қосады.
- Жазбаны өңдейді немесе өшіреді.
- **«Excel жүктеу»** және **«PDF жүктеу»** арқылы тізімді тойханаға береді.
- **«Еске салу мәтіні»**: дайын мәтін мен сілтемені көшіріп, WhatsApp тобына салады.
- **«QR жүктеу»**: қағаз шақыруға басатын PNG (кемінде 1000×1000) немесе SVG.

## 4. Деректер моделі

```
invitation
  id (uuid), slug (unique), status (enum), template_id, event_type (enum)
  languages (array: kk, ru), title_kk, title_ru, hosts_text_kk, hosts_text_ru
  event_at (timestamptz, Asia/Almaty), venue_name, venue_address, venue_lat, venue_lng
  program (jsonb: [{time, text_kk, text_ru}]), photos (array of file ids)
  music_file_id (nullable), voice_file_id (nullable)
  rsvp_open (bool), rsvp_deadline (timestamptz, nullable)
  owner_token (unique), preview_token (unique)
  plan (enum: ready, family, constructor), price_kzt (int), promo_code_id (nullable)
  paid_at, paid_by_admin_id, refunded_at, refund_reason
  is_portfolio (bool), expires_at (= event_at + 90 days)
  created_at, updated_at

rsvp
  id (uuid), invitation_id (fk), name, attending (bool), guests_count (int 1–10)
  phone (nullable), wish (nullable), source (enum: link, qr, manual)
  consent_at (timestamptz; null for manual), device_key (nullable)
  created_at, updated_at

template
  id, name, event_types (array), preview_image, config (jsonb: colors, fonts, layout), is_active

promo_code
  id, code (unique), kind (enum: discount, partner), amount_kzt or percent
  partner_name (nullable), max_uses, used_count, valid_until

file
  id, kind (photo, audio, og), storage_key, mime, size, created_at

admin_user
  id, email, password_hash (argon2/bcrypt), totp_secret, created_at
```

Әкімші API-і сессия арқылы жұмыс істейді (httpOnly cookie, CSRF қорғанысы). Той иесінің API-і тек токен арқылы.

## 6. Функционалдық емес талаптар

### 6.1 Өнімділік және үйлесімділік
- Шақыру беті 4G байланысында, орташа Android телефонда **2.5 секунд ішінде** ашылады (LCP ≤ 2.5s). Беттің салмағы фотосыз 300 КБ-тан аспайды.
- Қолдау көрсетілетін ортада: Android 8+ (Chrome, WhatsApp ішіндегі браузер), iOS 14+ (Safari, WhatsApp ішіндегі браузер). **WhatsApp ішіндегі браузерде міндетті түрде тексеріледі.**
- Экранның ені 320px-тен бастап дұрыс көрінеді.
- Әр шақыру 1 000 қонақтың кіруін және 500 RSVP-ді көтереді.

### 6.2 Сенімділік
- Сайттың жұмыс істеу уақыты (uptime) ≥ 99.5%, мониторинг жасалады (мысалы, UptimeRobot), істен шықса әкімшіге хабар келеді.
- Дерекқордың сақтық көшірмесі күн сайын жасалып, 14 күн сақталады. Қалпына келтіру тест ретінде айына бір рет тексеріледі.
- Тойдың алдындағы 48 сағатта ешқандай жаңарту (deploy) жасалмайды. Бұл тәжірибелік ереже.

### 6.3 Қауіпсіздік және дербес деректер
- Қазақстанның «Дербес деректер және оларды қорғау туралы» заңын сақтау керек. Заңгермен тексеріңіз.
- RSVP-де келісім белгісі (чекбокс) мен құпиялық саясатына сілтеме болады. Келісім берілген уақыт (`consent_at`) жазылады.
- **Тойдан 90 күн өткен соң** `rsvp` жазбаларындағы аты-жөн, телефон және тілек автоматты түрде өшіріледі (күнделікті cron тапсырмасы). Тек жалпы сандар қалады.
- Дерекқор мен сақтау орны мүмкіндігінше Қазақстан аумағында болады. Заңның деректерді елде сақтау талабын заңгермен нақтылаңыз.
- Тек HTTPS. Токендер URL-да болғандықтан, `/manage/` беттері іздеу жүйелерінен жабылады (noindex) және басқа сайттарға ақпарат жібермейді (`Referrer-Policy: no-referrer`).
- Енгізілген мәтіндердің бәрі XSS-тен қорғалады (escape). Жүктелетін файлдың түрі мен көлемі тексеріледі: фото ≤ 10 МБ, аудио ≤ 5 МБ.
- Әкімші паролі argon2 немесе bcrypt арқылы хэштеледі, TOTP бар, сәтсіз кіру әрекеттеріне шек қойылады.

### 6.4 Қолжетімділік
- Мәтін контрасты WCAG AA деңгейінен төмен болмайды (`brand.md` түстері тексерілген). Алтын түс `#C9A227` мәтінге қолданылмайды.
- Батырмалардың ең кіші өлшемі 44×44px, ал үлкендерге арналған режимде 56px.
- Барлық суретте `alt` мәтіні бар.

### 6.5 Тіл
- Интерфейстің барлық мәтіні қазақ және орыс тілдерінде, i18n файлдарында сақталады.
- Шрифттер қазақ әріптерін (Ә Ғ Қ Ң Ө Ұ Ү Һ І) толық қолдайтыны тексеріледі (`brand.md`: Lora, Inter).

## 9. Қабылдау критерийлері (MVP)

Мына тексерулердің бәрі өтсе, MVP дайын деп саналады:

- [ ] Әкімші шақыруды **15 минуттан аз** уақытта жасап, алдын ала көріністі жібере алады.
- [ ] Алдын ала көріністе су белгісі тұрады, RSVP жұмыс істемейді.
- [ ] «Төленді» басылғаннан кейін шақыру жарияланады, той иесі өз панелінің сілтемесін алады.
- [ ] Шақыру WhatsApp-та жіберілгенде чатта сурет, аты-жөндер және күні көрсетіледі.
- [ ] Шақыру WhatsApp ішіндегі браузерде (Android 8 және iOS 14) ашылып, RSVP жіберіледі.
- [ ] Үлкендерге арналған режимде мәтін 22px-тен кіші емес, ал екі батырма бір экранға сыяды.
- [ ] QR-кодты сканерлегенде шақыру ашылады, ал жауап тізімге `source=qr` болып түседі.
- [ ] Той иесі қонақты қолмен қоса алады, жиынтық сан бірден жаңарады.
- [ ] XLSX файлы Excel-де және Google Sheets-те дұрыс ашылады, қазақ әріптері бұзылмайды.
- [ ] Бір құрылғыдан қайта жауап берілсе, бұрынғы жауап жаңарады, жаңа жазба қосылмайды.
- [ ] Тойдан 90 күн өткенде қонақтардың дербес деректері өшеді (тест ортасында күнді өзгертіп тексеріледі).
- [ ] `LAUNCH30` промокоды 30 рет қолданылғаннан кейін жұмысын тоқтатады.
- [ ] Есепте алдын ала көріністен төлемге өту пайызы көрсетіледі.
- [ ] Lighthouse Mobile: Performance ≥ 85, Accessibility ≥ 90.
